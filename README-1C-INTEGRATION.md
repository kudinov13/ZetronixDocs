## Как это работает (обзор)

```
┌─────────────┐     ┌──────────────────┐     ┌─────────┐
│  Клиент     │────▶│  ZenzaDocs-Server│────▶│   1С    │
│  (Electron) │     │  (админ-панель)  │     │  база   │
└─────────────┘     └──────────────────┘     └─────────┘
```

**Поток данных:**

1. **Клиент** распознаёт документ (счёт, УПД, акт и т.д.) через AI
2. **Клиент** обращается к 1С: `GET /config` → определяет тип конфигурации (Бухгалтерия, УТ, ERP, ...)
3. **Клиент** обращается к 1С: `GET /schema` → получает структуру документов 1С
4. **Клиент** отправляет тип конфигурации + схему на **ZenzaDocs-Server**
5. **Сервер** отдаёт маппинг:
   - Если у клиента **стандартная** 1С → **пресет** (автоматически)
   - Если **кастомная** → **кастомный маппинг** из БД (настраивается в админке)
6. **Клиент** применяет маппинг и отправляет `POST /documents` в 1С
7. **1С модуль** принимает JSON и создаёт документ в базе

## Установка для клиента

### Шаг 1: Установка HTTP-модуля в 1С

1. Откройте **Конфигуратор 1С** клиента
2. Создайте HTTP-сервис со следующими параметрами:
   - **Имя:** `DocumentOborotAPI`
   - **Корневой URL:** `documentoborot`
3. Скопируйте код из файла `1c-integration/http_service_module.bsl` в модуль HTTP-сервиса
4. Нажмите **F7** (обновить конфигурацию базы данных)
5. Опубликуйте HTTP-сервис: **Администрирование → Публикация на веб-сервере**

### Шаг 2: Создание справочника "ЗагруженныеДокументы"

| НомерДокумента | Строка(50) |
| ДатаДокумента | Строка(20) |
| КонтрагентНаименование | Строка(200) |
| КонтрагентИНН | Строка(20) |
| КонтрагентКПП | Строка(20) |
| КонтрагентАдрес | Строка(300) |
| ПоставщикНаименование | Строка(200) |
| ПоставщикИНН | Строка(20) |
| ПоставщикКПП | Строка(20) |
| ПоставщикАдрес | Строка(300) |
| Сумма | Число(15,2) |
| СуммаНДС | Число(15,2) |

### Шаг 3: Настройка в приложении клиента

Клиент открывает приложение → Настройки → Интеграция с 1С:
- **URL HTTP-сервиса:** `http://1c-server/base/hs/documentoborot`
- **Логин:** пользователь 1С с правами на HTTP-сервис
- **Пароль:** пароль пользователя 1С
- Нажать **"Проверить"** — должно показать "Подключение к 1С успешно"

## Настройка в админ-панели

### Для стандартных 1С (90% клиентов)

**Ничего настраивать не нужно!** При первом отправке документа:
1. Приложение определяет тип 1С автоматически (через `GET /config`)
2. Сервер подбирает готовый пресет
3. Документы отправляются с правильным маппингом

### Для кастомных 1С (10% клиентов)

1. Откройте админ-панель: `https://api.zetronix.ru/admin`
2. Перейдите на вкладку **"1С Маппинги"**
3. В разделе **"Редактор маппинга"**:
   - Введите **Key ID** клиента
   - Выберите **тип конфигурации** (можно начать с пресета и изменить)
   - Нажмите **"Загрузить пресет"** — заполнит JSON ближайшим пресетом
   - Отредактируйте JSON под структуру клиента
   - Нажмите **"Сохранить маппинг"**
4. Клиент получит кастомный маппинг при следующем отправлении документа

### Просмотр схемы 1С клиента

Когда клиент впервые отправляет документ, его схема 1С автоматически сохраняется на сервере. В админ-панели на вкладке "1С Маппинги" видно:
- Тип конфигурации
- Имя конфигурации
- Сохранённую схему (документы, реквизиты, табличные части)

## Стандартные конфигурации 1С (пресеты)

Пресеты хранятся в `ZenzaDocs-Server/src/onec-presets.js`:

| Тип | Конфигурация | Описание |
|---|---|---|
| `accounting` | 1С:Бухгалтерия 8.3 | Самая частая. Счета, УПД, акты, накладные |
| `trade` | 1С:Управление торговлей | Торговые документы, партнёры |
| `erp` | 1С:ERP | Полная ERP, партнёры, получатели |
| `complex` | 1С:Комплексная автоматизация | Объединяет бухгалтерию и торговлю |

### Структура пресета

```json
{
  "config_type": "accounting",
  "config_name": "1С:Бухгалтерия 8.3",
  "document_type_mapping": {
    "schet": "СчетНаОплатуПокупателю",
    "upd": "СчетФактураВыданный",
    "akt": "АктВыполненныхРабот",
    "nakladnaya": "РеализацияТоваровУслуг"
  },
  "metadata_mapping": {
    "Поставщик": "Контрагент",
    "ИНН поставщика": "КонтрагентИНН",
    "Итого к оплате": "СуммаДокумента"
  },
  "table_mapping": {
    "tabular_section": "Товары",
    "column_mapping": {
      "Наименование": "Номенклатура",
      "Количество": "Количество",
      "Цена": "Цена"
    }
  }
}
```

### Добавление нового пресета

Если появилась новая стандартная конфигурация 1С:

1. Откройте `ZenzaDocs-Server/src/onec-presets.js`
2. Добавьте новый ключ в объект `PRESETS`
3. Заполните `document_type_mapping`, `metadata_mapping`, `table_mapping`
4. Перезапустите сервер

## Кастомные конфигурации 1С

Для нестандартных 1С маппинг настраивается индивидуально:

1. В админ-панели → "1С Маппинги" → "Редактор маппинга"
2. Укажите Key ID клиента
3. Загрузите ближайший пресет кнопкой "Загрузить пресет"
4. Отредактируйте поля под структуру клиента:
   - `document_type_mapping` — какой тип документа 1С создавать
   - `metadata_mapping` — маппинг полей шапки документа
   - `table_mapping` — маппинг табличной части и колонок
5. Сохраните

Клиент получит маппинг автоматически при следующем отправлении документа.

## API эндпоинты

### Клиентские (без авторизации)

| Метод | URL | Описание |
|---|---|---|
| POST | `/api/client/onec-mapping` | Получить маппинг для клиента (по keyId + configType) |
| POST | `/api/client/onec-schema` | Сохранить схему 1С клиента на сервере |

### Админские (требуют JWT)

| Метод | URL | Описание |
|---|---|---|
| GET | `/api/admin/onec-mappings` | Список всех маппингов |
| GET | `/api/admin/onec-mappings/:id` | Получить один маппинг |
| POST | `/api/admin/onec-mappings` | Сохранить/обновить маппинг |
| POST | `/api/admin/onec-mappings/delete` | Удалить маппинг |
| GET | `/api/admin/onec-presets` | Список доступных пресетов |

### 1С HTTP-сервис (в базе клиента)

| Метод | URL | Описание |
|---|---|---|
| GET | `/ping` | Проверка доступности |
| GET | `/config` | Автоопределение типа конфигурации |
| GET | `/schema` | Структура документов 1С (метаданные) |
| POST | `/documents` | Приём документа |
| GET | `/documents` | Список сохранённых документов |

## Устранение проблем

### "Подключение к 1С успешно", но документы не отправляются

1. Проверьте, что справочник "ЗагруженныеДокументы" создан с правильными реквизитами
2. Проверьте, что у пользователя 1С есть права на запись в справочник
3. Посмотрите журнал регистрации 1С

### Документы отправляются, но поля заполнены неправильно

1. Проверьте маппинг в админ-панели → "1С Маппинги"
2. Если стандартная 1С — проверьте, что пресет подходит (сравните поля)
3. Если кастомная — отредактируйте маппинг вручную

### "HTTP-сервис 1С не найден"

1. Проверьте URL в настройках приложения
2. Убедитесь, что HTTP-сервис опубликован: Конфигуратор → Администрирование → Публикация
3. Проверьте, что веб-сервер (IIS/Apache) работает

### "Устаревший HTTP-модуль"

В приложении есть проверка версии модуля. Если версия < 4:
1. Замените код модуля на актуальный `http_service_module.bsl`
2. Нажмите F7 в конфигураторе
3. Обновите веб-публикацию

### Маппинг не применяется

1. Проверьте, что у клиента есть лицензия (keyId)
2. Проверьте, что сервер доступен (`https://api.zetronix.ru/api/health`)
3. Очистите кэш маппинга: перезапустите приложение
4. Проверьте в админ-панели, что маппинг сохранён для этого keyId
